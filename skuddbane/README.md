# Skuddbane

Ballistikkalkulator som PWA. Virker uten nett etter første åpning.

Filer: index.html, manifest.webmanifest, sw.js, icons/.
Legg alle filene i rota av et GitHub-repo og slå på GitHub Pages (Settings → Pages → Deploy from branch → main / root).
Åpne adressen i Safari og velg Del → Legg til på Hjem-skjerm.

Ved oppdatering: endre CACHE-navnet i sw.js (f.eks. skuddbane-v2) så telefonen henter ny versjon.
